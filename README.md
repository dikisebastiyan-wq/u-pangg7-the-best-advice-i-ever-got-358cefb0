An entry for [The Best Advice I Ever Got](https://make.fun/bounty/u-pangg7-the-best-advice-i-ever-got-358cefb0) on [make.fun](https://make.fun).

The program writes a single sentence to `entry.txt` — the best advice the writer ever received, as told by his father counting tips at the kitchen table after every double shift: put the first dollar of every payday aside, and live on whatever was left.

## Run it

```sh
node main.ts
```

`main.ts` writes one sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `/output/entry.txt` when the variable is not set).
It is deterministic, needs no network, no dependencies, and finishes
in well under a second.
